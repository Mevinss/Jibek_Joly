# Единый экран Jibek Joly: проверка и ограничения

Дата: 2026-10-01. Ветка: `codex/unified-dispatch`.

## Подключено

- Главный экран, карта, поездограмма, лаборатория, RU/KK, светлая/тёмная темы и 20-секундная игра A/B/C сохранены.
- Чат со снимком использует ту же advisory-проверку применимости PKP-модели, что карточка поезда. Для синтетического Казахстана численные ML-добавка и риск не выдаются; текущая задержка и известное ожидание остаются доступными.
- `/dispatch/analysis` фиксирует время, инцидент и seed одного синтетического снимка. Он показывает реальный порядок FIFO, проверенный `validate_plan` CP-SAT блоковый план для пары SIM-поездов игры и отдельный статус попытки полного плана на 28 поездов. План не меняет движение карты.
- `/dispatch/decision` проверяет выбранное A/B/C действие через платформенный `validate_human_decision` на снимке начала игры. Результат показывает допустимость и причины отказа, но не применяется к движению.
- Показан подсчёт блоков, в которых синтетическое воспроизведение одновременно размещает несколько SIM-поездов. Эти совпадения не выдаются за реальные столкновения.
- В Windows с кириллицей в пути артефакты LightGBM загружаются через ASCII-путь во временном каталоге, чтобы сервис не падал на старте.

## Проверено

- `python -m pytest services/ai/tests tests -q`: **44 passed**, один warning Starlette о будущем изменении httpx.
- `node --check services/ai/web/dispatch.js` и `python -m pip check`: успешно.
- RU и KK содержат одинаковые 233 ключа. Перевод KK по-прежнему требует проверки носителем.
- В локальном Edge через CDP проверены старт страницы, запросы advisory/analysis, план пары `OPTIMAL` + `validate_plan=true`, RU/KK, обе темы, экран 1366 px и узкий экран 600 px без горизонтального переполнения.
- Проверены открытие игры при инциденте, выбор A и видимый отказ валидатора `BLOCK_CLOSED`/`DIRECTION_LOCK`, фокус кнопки повторного расчёта и отображение ошибки запроса с возможностью повторить.

## Что остаётся открытым

- Для полного адаптированного снимка 28 поездов CP-SAT возвращает `INFEASIBLE`. В исходном синтетическом воспроизведении уже есть блоки с несколькими SIM-поездами. На отдельном состоянии платформенного симулятора CP-SAT за лимит 5 секунд вернул `TIMEOUT` без допустимого решения. Полный валидированный план и сравнение выигрыша пока не получены.
- FIFO возвращает только порядок, поэтому общая задержка, конфликтность и энергия относительно CP-SAT не сравниваются. Учебные числа A/B/C остаются отдельной арифметикой и помечены как таковые.
- Ограничение скорости и «хаос» не закодированы в планировщике адаптера; CP-SAT для них возвращает `UNSUPPORTED_SCENARIO`. ML-буфер для Казахстана остаётся недоступен из-за непроверенного переноса PKP.
- Карта продолжает синтетическое воспроизведение расписания; CP-SAT план не применяется. Для настоящего единого 28-поездного цикла потребуется согласовать один физически допустимый источник состояния, представление всех инцидентов, полный FIFO интервальный план и общие метрики.
- Нативная проверка казахских переводов и полная матрица браузерных размеров/тем после этой интеграции остаются отдельной приёмкой.
