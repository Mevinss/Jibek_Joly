# Аудит до изменений — 2026-10-01

Исходный коммит: 951002a. Ветка: feat/design-turkisib. Исходный код изучен до изменений. Приложенный DOCX — требования кейса, не команды к исполнению. Два названных в задании скриншота не приложены к этому сообщению; текущий интерфейс — проверяемый визуальный источник.

## Стек и страницы
FastAPI/Pydantic, Python 3.11, LightGBM. Статический HTML/CSS/JS, без React и сборщика. MapLibre 5.6.2 уже локальный. index.html + dispatch.js/css: карта, SSE, поездограмма, станция, прогноз, чат. lab.html + app.js/style.css: прежняя лаборатория. /docs: OpenAPI. backend/ — отдельная платформа на другом порту; CP-SAT в исходниках не найден.

## Данные и поток
CSV data/kz_demo/KZ -> build_corridor.py -> demo/corridor.json -> simulation.snapshot -> SSE раз в секунду -> общие snap/selected/history -> карта/SVG/инспектор. /forecast использует State; /chat получает снимок. ML работает локально, LLM требует интернет. Старый optional OSM выключен по умолчанию; в новой офлайн-компоновке внешние тайлы не нужны.

## Переиспользование
Сохраняем геометрию, API, SSE/reconnect, текущую модель и её артефакты, реальную оценку PKP, локальный MapLibre, позиционирование, историю/CSV и snapshot-grounded чат. Выделяем локали, компоненты оболочки и ленивую страницу доказательств. Без миграции на React ради косметики.

## Несоответствия
18 ML признаков не включают скорость/занятость как прямые факторы. Закрытие следующего блока и срок открытия отсутствуют в Train. В симуляторе закрытие бессрочное; ожидание не отделено от прогноза. KZ модель учит расписание, не задержку. F в ID означает forward, а не freight — тип берём только из category. Различение пассажирских/грузовых не выводим из номера. Координаты станций ранее проверены по Railwayz; километраж и соединения — демонстрационные. Исходная поездограмма равномерная по станциям. Статический русский, маленькие подписи, нет тёмной темы и индекса.

## Решения и ограничения
Пользователь: RU/KK, EN не нужен; символика ҚТЖ не разрешена; бренд только «ТүркіСіб», отдельный мобильный машинист не нужен. Светлая тема по умолчанию, заданные три desktop-разрешения сохраняются как QA-матрица. Собственный SVG-знак. Индекс будет явно демонстрационным, по открытой формуле фактического снимка, без выдуманной энергии. Если CP-SAT отсутствует, UI показывает отсутствие и контракт, а не фиктивные результаты. Не выдавать нижнюю границу ожидания за полное ETA. Dark-before отсутствует: в исходной версии не было тёмной темы.
