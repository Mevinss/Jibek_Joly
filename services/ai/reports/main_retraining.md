## Обучение и результат

После прежних правил очистки подготовлено 530 887 строк. Официальное разбиение: **372 800 train / 79 655 validation / 78 432 test**. Рейсы не пересекаются. Статистики перегона/станции строятся только на train, а для обучающих строк — вне собственного рейса через групповые folds. Исключены восстановленные предыдущие задержки; `difficulty_id` используется только при построении целевой прокси-метки.

| Проверка | MAE изменения задержки, мин | ROC-AUC | PR-AUC |
|---|---:|---:|---:|
| Прежняя модель, официальный test | 0.585917 | 0.879730 | 0.265832 |
| Переобученная из main, тот же test | 0.585917 | 0.879730 | 0.265832 |
| Повторная проверка март → апрель → май | 0.822677 | 0.838030 | 0.233758 |

Обе обученные версии прошли существующий gate относительно baseline. На официальном test baseline нулевого изменения даёт MAE 0.653228, медианы перегона — 0.647147. Порог прокси-оценки 0.103632: precision 0.198179, recall 0.755619. Ложных предупреждений много. Проверка по месяцам также воспроизвела прежние результаты. Настройки не подбирались для выигрыша на повторно просмотренном test.

## Подключение и воспроизведение

Активный каталог задаётся `model_directory: forecast_main` в `services/ai/config/forecast.yaml`. Старая `forecast_v1` сохранена. Порог ML читается из метаданных именно загруженного артефакта, поэтому проверка отдельного кандидата не применяет случайно порог другой версии.

```powershell
.\.venv\Scripts\python.exe -m services.ai.scripts.sync_main_data --ref 298694c0dccc564bc686560a9e98bbaae3c76900
.\.venv\Scripts\python.exe -m services.ai.training.train --data-dir data/main-source/data/external/pkp/pkp_intercity_delays_dataset --output-dir services/ai/models/forecast_main --model-version pkp-main-298694c --source-commit 298694c0dccc564bc686560a9e98bbaae3c76900
.\.venv\Scripts\python.exe -m services.ai.training.train --data-dir data/main-source/data/external/pkp/pkp_intercity_delays_dataset --output-dir services/ai/models/forecast_main_temporal --model-version pkp-main-298694c-temporal --source-commit 298694c0dccc564bc686560a9e98bbaae3c76900 --temporal
.\.venv\Scripts\python.exe -m pytest services/ai/tests -q
```

22 теста пройдены, включая контроль изменённых входных файлов, запрет выхода путей за каталог, явный отказ при отсутствующем указанном датасете и использование порога текущей модели. Явный `--output-dir` не меняет настройки обслуживаемой модели. Для экспериментов выбирайте новый каталог; активируйте после сравнения.

Контракт симулятора `GET /api/state` из main отличается от AI `State`; прямое подключение без адаптера не заявляется. Перенос пассажирской модели PKP на синтетический казахстанский участок по-прежнему не валидирован. Грузовые поезда используют явно обозначенные правила. Прокси-событие не означает подтверждённый конфликт или проверенный горизонт 15 минут.
