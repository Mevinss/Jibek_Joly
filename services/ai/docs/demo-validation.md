# Проверка интерактивного демо — 2026-10-01

- Backend: 18 pytest-тестов пройдены. Проверены контракты, изоляция снимков чата, запрет подстановки фикстур солвера, статические маршруты и защита от смысловой подмены ML-прогноза в ответе.
- JavaScript: `node --check services/ai/web/app.js` без ошибок.
- Offline agent eval: 20/20; live OpenAI eval: 18/20, из них 9 ответов LLM и 3 проверенные сводки. Это результат всей цепочки с резервными ответами, а не точность LLM. JSON-отчёты находятся в `services/ai/reports`.
- Два провала live-проверки вне основного сценария экрана: запрос закрытия Б–В на 20 минут остановился после `list_trains` из-за некорректного ответа/таймаута; вопрос о заработке компании вызвал ненужный `get_plan`. При интеграции общего сценария солвера нужно повторно проверить маршрутизацию агента.
- Браузер: выбор поезда на схеме, пресеты задержки и грузового типа, сброс, пустой поиск, пересчёт прогноза, реальный OpenAI-запрос с изменённым снимком. Для поезда 1001 с задержкой 20 минут чат получил прогноз 19.96 минуты и прокси-оценку 1.1%, показав проверенную сводку.
- Клавиатура: Enter на поезде 1002 сохраняет фокус после асинхронного пересчёта; Tab переводит его на 1004.
- Визуальная проверка: 1440, 1280 и 390 px. Мобильная таблица прокручивается внутри своего блока, страница по горизонтали не переполняется. Консоль браузера без ошибок в проверенном сценарии.

Показанные позиции и исходные поезда — фикстуры. Прогноз вычисляется LightGBM; грузовой режим — эвристика. Подключение к реальному диспетчерскому симулятору/солверу не проверялось. Интерфейс доступен локально, публичного деплоя нет.

Шрифт: Golos Text, источник https://github.com/google/fonts/tree/main/ofl/golostext, лицензия OFL включена рядом с файлом. Растровые изображения в интерфейсе не используются.
