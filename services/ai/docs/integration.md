# Подключение команды

Порт AI: 8002. Запуск из корня: `python -m services.ai.main`. Все URL задаются в `.env`; Docker не требуется. Приложение слушает только localhost.

Первичные JSON Schema находятся в `/contracts`. Это предложение контракта для командного PR; существующих контрактов в репозитории не было. Дальнейшие изменения нужно согласовать с владельцами платформы, солвера и UI.

| Потребитель | Метод AI | Тело / результат |
|---|---|---|
| Платформа | POST /forecast | `{trains, infra}` → массив Forecast |
| UI | POST /chat | `{messages:[{role,content}],session_id}` → SSE |
| Платформа/UI | POST /telegram | `{incident,context?}` → `{text,mode}`; не отправляет сообщения |
| Платформа | POST /report | `{analytics}` → `{markdown,mode}` |
| Наблюдаемость | GET /health, /metrics, /forecast/model-info | Статус, время инференса, модель |

SSE события: `tool_call`, `tool_result`, `token`, `error`, `done`. `error` с `recoverable=true` означает переключение на резервный ответ; клиент продолжает читать поток до `done`. Текст буферизуется до проверки чисел и затем выдаётся частями. Это не сквозная передача непроверенных токенов провайдера. session_id — метка запроса; история приходит в messages, сервер не хранит диалоги.

При `USE_FIXTURES=0` адаптер ожидает от платформы GET `/state`, `/trains`, `/trains/{train_id}`, `/plan`, `/index`, `/incidents`; от солвера POST `/whatif` с `{state,incident}` и POST `/advice` с `{state,train_id}`. Это предлагаемые пути до подтверждения командой; совместимость с ещё не предоставленными сервисами не проверена. Ошибка upstream возвращается как недоступность данных, без тихой подмены фикстурой.

Песочница обязана работать на копии snapshot. AI не имеет метода применения плана или записи инцидента. Единственный POST к солверу — вычисление what-if/advice. Фикстура what-if поддерживает только закрытие Б–В (B-C) на 20 минут; другие сценарии честно возвращают отсутствие примера.

Регламент LLM: максимум пять раундов инструментов; один повтор сетевого запроса; общий таймаут ответа; до 20 запросов в минуту на один процесс для платных маршрутов. Числовой grounding проверяет присутствие чисел в фактах с округлением, но не доказывает правильность привязки цифры к сущности. Перед публичным размещением нужны аутентификация и распределённые лимиты; сейчас это локальное демо.

Варианты what-if отображаются детерминированно по ответу инструмента (`mode=tool_summary`), после выбора инструмента агентом. Это не даёт LLM перепутать суммарную задержку с приростом задержки или выдать выдуманное сравнение с FIFO. Для прочих ответов префикс фикстур добавляется сервером независимо от текста LLM.

Тексты телеграммы и рапорта в v1 детерминированные: сохраняют разделы и факты. Полировка через LLM оставлена отдельной функцией, но не включена в маршруты.
