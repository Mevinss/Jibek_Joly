# ML и LLM сервис

Запуск, данные, результаты и ограничения описаны в [корневом README](../../README.md).

Основные точки входа: `python -m services.ai.main`, `python -m services.ai.training.train`, `python -m services.ai.eval.run_agent_eval`. Все команды выполняются из корня репозитория.

Документы: [перенос модели](docs/sim_to_real.md), [API для команды](docs/integration.md), [аудит данных](reports/data_audit.md). Swagger доступен на `/docs`, спецификация OpenAPI на `/openapi.json`.
